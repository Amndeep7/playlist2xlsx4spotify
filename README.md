# playlist2xlsx4spotify

Rust CLI to take Spotify playlists and convert them into XLSX files.

The intent is to automate the process of extracting all of the tracks' names, album names, and artist(s) names into a spreadsheet so that I can a) keep track of which songs I want to vote for in Music League and b) more easily look up those tracks on YouTube as I make a YT version of the playlist.
